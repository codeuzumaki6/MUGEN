# Referencia de animación de Mamushi

El usuario aportó `VaydraSenki.mp4` (73.71 segundos) para pulir los especiales. El video se usa como referencia visual de Vaydra; no se atribuye su implementación de Naruto Senki como código de MUGEN. El hash y los intervalos observados se conservan en `reference_analysis.json`.

Adaptación: brazo que se extiende y recoge, ráfaga de espinas en tres alturas, embestida con anillos de viento, raíz que emerge de un punto del suelo y se retrae, maza con impacto en el piso, y una mandíbula que carga una esfera violeta. Esta última usa las poses originales 0,81/82 y sustituye el antiguo asalto de RT. El ataque de copias de la ultimate y la multiplicación autónoma permanecen como estaban.

Las 80 entradas originales de cuerpo y partes de armas conservan sus píxeles, colores, ejes y escala. Los efectos adicionales de viento, tierra y energía vienen del Code de MUGEN STARS que ya había aportado el usuario; véase `Mamushi/CREDITOS_Y_FUENTES.md`. No se genera ni se repinta el cuerpo con IA. El dash usa los cuadros de desplazamiento existentes, con movimiento por el suelo y frenado finito.
