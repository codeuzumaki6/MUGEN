# Controles Xbox — Naruto BTM

X=a, Y=b, B=c, A=x, RB=y, RT=z y Pausa=s. Las direcciones suponen que miras a la derecha; invierte los cuartos de círculo al mirar a la izquierda.

| →→ / ←← | Dash en ambos sentidos | 0 |
| ↓↘→ + X | Rasengan: avance e impacto | 350 |
| ↓↙← + X | Doton: muro de tierra | 400 |
| ↓↘→ + Y | Rasenshuriken arrojado con explosión | 450 |
| ↓↙← + Y | Combo de puño y patada de chakra | 450 |
| ↓↘→ + B | Patada ascendente | 350 |
| ↓↙← + B | Asalto descendente | 450 |
