# Controles de Delta Kara

Correspondencia: X=a, Y=b, B=c, A=x, RB=y, RT=z y Pausa=s en MUGEN. Si tu mando usa otra asignación, ajústala en las opciones.

| Entrada | Técnica | Energía |
|---|---|---:|
| X, X, X / Y, Y, Y / B, B, B | Tres cadenas terrestres y aéreas; enlazan al acertar | 0 |
| →→ / ←← | Dash en ambas direcciones | 0 |
| ↓↘→ + X | Pistón: asalto con brazos modificados | 300 |
| ↓↙← + X | Lanza con pierna mecánica | 350 |
| ↓↘→ + Y | Rayo destructor rosa, interferencia de curación de 5 s | 500 |
| ↓↙← + Y | Picado con propulsores | 450 |
| ↓↘→ + B | Ascenso con propulsores y remate | 400 |
| ↓↙← + B | Impacto descendente de área | 500 |
| ↓ + X | Barrido bajo | 200 |
| ↓ + Y | Lanzador | 300 |
| ↓ + B | Onda de presión cercana | 400 |
| RB | Rayo ocular dirigido; también en el aire, interferencia de 3 s | 200 |
| RT | Embestida propulsada | 350 |
| ↓ + RB | Absorción ocular de energía; almacena hasta 3 cargas | 150, recupera 220 al absorber |
| ↓ + RT | Devuelve una carga absorbida | 250 y 1 carga |
| RB + RT en el aire | Activa/desactiva vuelo; flechas para moverse | 25 cada 15 ticks |
| Mantener Pausa | Cargar energía con aura rosa | 0 |
| ↓ + Pausa | Sobrecarga de 12 s: +20 % de daño, enfriamiento de 25 s | 1500 |
| A | Autodestrucción de área; **sin coste de vida** | 3000 |

Las direcciones de los cuartos de círculo se invierten al mirar hacia la izquierda. El vuelo dura como máximo 8 s y consume combustible. La sobrecarga no agranda el cuerpo ni da invulnerabilidad permanente.
