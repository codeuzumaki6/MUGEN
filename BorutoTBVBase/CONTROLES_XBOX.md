# Controles Xbox — Boruto TBV base

X=a, Y=b, B=c, A=x, RB=y, RT=z y Pausa=s. Las flechas suponen que miras a la derecha; invierte los cuartos de círculo al mirar a la izquierda.

| Entrada | Técnica | Energía |
|---|---|---:|
| X / Y / B al acertar | Tres cadenas de espada y taijutsu | 0 |
| X / Y / B en el aire | Cadenas aéreas de hasta tres ataques | 0 |
| →→ / ←← | Dash en ambos sentidos | 0 |
| ↓↘→ + X | Ráfaga de Rasengan con avance | 350 |
| ↓↙← + X | Onda de Shiden | 400 |
| ↓↘→ + Y | Embestida de katana | 450 |
| ↓↙← + Y | Uzuhiko: envoltura, palma y tornado | 550 |
| ↓↘→ + B | Corte ascendente | 350 |
| ↓↙← + B | Combo Shiden y erupción eléctrica | 450 |
| ↓ + X | Barrido de espada | 200 |
| ↓ + Y | Clon autónomo con katana | 300 |
| ↓ + B | Hiraishin: golpe aéreo | 450 |
| RB | Tajo arrojado | 200 |
| RT | Rasengan compacto | 250 |
| ↓ + RB | Hiraishin: desplazamiento y corte | 600 |
| ↓ + RT | Hiraishin: Rasengan descendente gigante | 600 |
| Mantener Pausa | Carga de energía con aura | 0 |
| ↓ + Pausa con 3000 | Concentración de Uzuhiko, veinte segundos | 1500 |
| A | Ulti: Uzuhiko completo | 3000 |

La concentración mantiene la ropa y apariencia TBV base, refuerza los ataques y conserva el capullo de viento durante todo el despertar. El clon tiene 120 de vida, dura hasta ocho segundos y puede ser destruido. Persigue al rival, repite sus ataques y espera de pie entre asaltos; sólo puede existir uno. Volver a pulsar abajo + Y ordena otro asalto al clon existente. Uzuhiko y la ulti muestran la palma golpeando al rival antes de sujetarlo. La ulti debe acertar: ocho impactos, un máximo de 650 de daño en base y 800 con concentración, sin consumir vida propia. Admite guardia, puede fallar por distancia y libera al rival si interrumpen a Boruto.
